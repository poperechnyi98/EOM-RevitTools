# Сечение лотков

Версия 0.2.1 перенесена из EOM Lab в MyRvtTools. Целевая среда — Revit 2024, pyRevit и IronPython 2.7.

## Запуск

1. Выполните **pyRevit → Reload**, если Revit уже открыт.
2. Откройте нужный вид разреза.
3. На вкладке **MyRvtTools → Оформление** нажмите **Сечение лотков**.
4. Выберите книгу `.xlsx` или `.xls`, затем расчётный лист. Нажмите **Построить** и укажите наружный нижний левый угол лотка.
5. В итоговом сообщении проверьте количество кабелей и занятый габарит. При выходе за габарит все кабели ставятся по исходным размерам.

Для построения нужно загруженное семейство **SMNX_DC_э_Сечение кабеля** категории «Элементы узлов» с доступными параметрами экземпляра «Диаметр», «Количество жил», «Сечение проводника». При чтении `.xls` используется xlrd, поставляемый с установленным pyRevit. Чтение `.xlsx` использует стандартную библиотеку Python. Microsoft Excel запускать не требуется. Команда считывает сохранённые результаты формул.

При создании кабелей команда заполняет текстовый параметр экземпляра `SMNX_Номер позиции`. Каждая строка Excel с одножильными кабелями получает общий номер. Кабели в каждом треугольнике нумеруются слева направо, а счёт продолжается между всеми треугольниками строки. Если в столбце D указано 2 КЛ по 5 кабелей, номера идут от `1.1` до `1.10`. Следующая строка с 1 КЛ и 5 кабелями получает номера от `2.1` до `2.5`. Многожильные кабели, включая кабели в пучках, получают по одному целому номеру из той же последовательности. Нумерация начинается с 1 для каждого построения. Параметр должен быть доступен для записи в семействе кабеля.

Контур строится линиями детализации стиля `<Тонкие линии>`. Ширина и высота из Excel относятся к наружному контуру. Толщина стенок и дна составляет 1,5 мм. У лестничного лотка кабели опираются на ступеньку в 19 мм от наружного дна, у листового — на внутреннее дно. Учитывается тип лотка, указанный на листе Excel. Контур одинаков для горизонтального и вертикального исполнения каждого типа.

Тип текста `SMNX_2.2` должен быть загружен в проект. Слева вертикально выводится значение из строки «Заполняемость, %» с одним десятичным знаком. Под лотком создаётся одна редактируемая текстовая заметка с отдельной строкой на каждую позицию. Диапазоны записываются как `1.1-1.10_Номер группы`, одиночные позиции — как `3_Номер группы`. Подставьте свой номер группы после подчёркивания.

Флажок **Номера групп заполнены** подставляет в список значения столбца K «Название КЛ». Если в ячейке перечислено несколько номеров через точку с запятой, запятую или перенос строки, они сопоставляются по порядку с КЛ по столбцу D. Для пучка число кабелей берётся из столбца E. Один номер применяется ко всей строке. Если в списке есть пропуски, для соответствующих позиций остаётся текст `Номер группы`. У одножильных кабелей отдельные подписи разделяют диапазон в заметке, сохраняя значения `SMNX_Номер позиции` у кабелей.

## Приёмка

- Первичная проверка версии 0.2.1 в EOM Lab на Revit 2024 пройдена по подтверждению автора. Контур, опорные отметки, процент, нумерация и подписи групп проверены автоматическими тестами.

- Для `.xls` проверена контрольная книга BIFF8 со скрытым листом и сохранённым результатом формулы диаметра.
- Если API не предоставляет контур оболочки для проверки, команда размещает экземпляр по точке вставки семейства и сообщает об этом в итогах. В этом случае следует проверить привязку центра кабеля на разрезе.

Чтобы получить команду из основного набора, выполните **MyRvtTools → Сервис → Обновить**.
