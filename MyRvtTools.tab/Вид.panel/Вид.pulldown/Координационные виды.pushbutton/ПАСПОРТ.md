# Координационные виды

Версия **0.2.15**. Команда открывает одно окно в стиле View Manager и работает с активной моделью и активным видом Revit.

## Возможности

- одна строка на тип Revit-связи слева;
- фильтр по названию связи и фильтр видов с поведением «2_ — только начинающиеся с 2_»;
- группировка связей, раскрытие и сворачивание групп;
- выбор одного координационного вида для каждой связи;
- импорт и экспорт JSON-профилей.

Кнопка «Применить» записывает `ByLinkView` и выбранный `LinkedViewId` для основной строки связи на активном виде. Команда снимает переопределения её экземпляров, чтобы они унаследовали настройки основной строки. Если для типа ещё не выбран связанный вид, команда подставляет прежний вид при совпадении назначений экземпляров.

## Установка и проверка

1. Перезагрузить pyRevit.
2. Открыть проект с загруженными связями и перейти на нужный вид.
3. Запустить **MyRvtTools → Вид → Коорд. виды на связях**.
4. Выбрать связь с несколькими экземплярами и назначить координационный вид.
5. Нажать «Применить» и открыть «Видимость/графика → Связи Revit». У основной строки должен отображаться режим «По связанному виду». У экземпляров флажок переопределения должен быть снят.

Автоматические проверки выполняются без Revit. Проверка в Revit 2024 ещё не выполнена.

Если в Revit включён оранжевый режим «Временные свойства вида» (например, отображение «Рабочие наборы»), его нужно выключить перед запуском: Revit блокирует в нём настройки графики связей.
