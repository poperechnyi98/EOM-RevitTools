# EOM-RevitTools

Расширение pyRevit для Autodesk Revit с инструментами раздела ЭОМ. В Revit появляется вкладка **MyRvtTools**.

Требования: Revit с установленным pyRevit 5.2. Git на компьютере пользователя не нужен — pyRevit сам скачивает и обновляет расширение с GitHub.

## Кнопки

### Сервис
- **Обновить** — скачивает последнюю версию расширения с GitHub и перезагружает pyRevit.

### Вид
- **View Manager** — закреплённая панель (вкладка рядом с «Диспетчером проекта»): группы рабочих наборов и все наборы активного вида в виде цветных плиток (зелёная — включено, серая — выключено, жёлтая — группа включена частично), с подгруппами 0 — Связи, 1 — Второстепенные, 2 — ЭОМ. Кнопка ⚙ у групп — настройка групп и «Наименование РБ» (сокращение имён на плитках по своим правилам); названия категорий сокращаются автоматически. Вкладка «Категории»: быстрые категории элементов и аннотаций (выбираются кнопкой ⚙) — такие же плитки; модельные категории и аннотации подчиняются своим пунктам шаблона вида. Если шаблон вида управляет рабочими наборами, изменения вносятся в шаблон только при включённой галочке «Разрешаю менять шаблон вида». Профиль групп сохраняется автоматически, его можно выгрузить в файл и загрузить. Каждое действие отменяется Ctrl+Z. После первой установки нужен один перезапуск Revit.

### Оформление
- **Размеры осей** — размерная цепочка и общий размер для выделенных осей на активном виде.
- **Размеры лотков** — цепочки линейных размеров по наружным граням выбранных кабельных лотков и фитингов.
- **Размеры ОКК** — цепочки линейных размеров по наружным граням коробов ОКК (воздуховоды и их соединительные детали).
- **Тип размера** — выбор типа линейного размера, который используют «Размеры лотков» и «Размеры ОКК».
- **Марки оборудования** ¹ — расстановка марок оборудования на виде ровно и без пересечений, в том числе для оборудования связей. Shift+клик — настройки.
- **Марки лотков** ¹ — то же для кабельных лотков.

### Навигация
- **ID элемента** — показывает и копирует ID выделенных элементов, в том числе внутри связанной модели.
- **Зум к элементу** — приближает активный вид к выделенному элементу или к элементу по ID.
- **Найти помещение** — поиск помещений в модели и связях по номеру или названию с приближением вида.
- **Оси и уровни связи** ¹ — сравнивает оси и уровни модели со связью КФП и показывает расхождения. Модель не меняет.

### Помещения
- **Экспликация фрагмента** ¹ — экспликация помещений модели и связей, попавших в подрезку активного плана.
- **Обновить экспликацию** ¹ — пересобирает созданные экспликации фрагментов.
- **Двухуровневые лоты** ¹ — находит в связи АР лоты, помещения которых стоят на двух уровнях; выгрузка в Excel.

### Моделирование
- **Обход вверх** — обход препятствия на прямом лотке или воздуховоде: подъём 200 мм, участок 300 мм, переходы под 45°.
- **Обход вниз** — то же со снижением на 200 мм.
- **ПН_ЭОМ_Воздуховоды** — назначает тип системы воздуховодам и соединительным деталям по имени типа (весь проект или выделение).

### В разработке
- **Сечение лотка** ¹ — сечение лотка с раскладкой кабелей по данным Excel. Будет переделано под наш вариант.

¹ Перенесено из расширения [LowLife](https://github.com/avpersiyanov-afk/LowLife) (автор — Андрей Персиянов, лицензия MIT, см. `lib/eomtools/LICENSE-LowLife.txt`) и будет дорабатываться под наши задачи.

## Установка

Закройте Revit и выполните в командной строке (cmd):

```
pyrevit extend ui EOM-RevitTools https://github.com/poperechnyi98/EOM-RevitTools.git --branch=main
```

Откройте Revit — должна появиться вкладка **MyRvtTools**.

### Альтернатива: через интерфейс pyRevit

1. **pyRevit → Settings → Custom Extension Sources** — добавьте ссылку:
   `https://raw.githubusercontent.com/poperechnyi98/EOM-RevitTools/main/extensions.json`
2. Сохраните настройки, откройте **pyRevit → Extensions**, найдите **EOM-RevitTools** и нажмите **Install**.
3. Перезапустите Revit (или **pyRevit → Reload**).

## Обновление

Нажмите **MyRvtTools → Сервис → Обновить**. Кнопка скачает последнюю версию из ветки `main` и перезагрузит pyRevit.

Штатная кнопка **pyRevit → Update** тоже обновляет расширение, но в некоторых сетях пишет «No internet access detected» и ничего не делает (pyRevit проверяет доступ к 8.8.8.8). Если не работает ни одна кнопка, закройте Revit и выполните:

```
pyrevit extensions update EOM-RevitTools
```

## Удаление

Закройте Revit и выполните:

```
pyrevit extensions delete EOM-RevitTools
```

## Важно

- Если раньше расширение было подключено как локальная папка (Custom Extension Directory), уберите её в настройках pyRevit, иначе вкладка появится дважды.
- Команды, которые изменяют модель, проверяйте на копии проекта.
